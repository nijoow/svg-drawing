## 실제 변경

1. **연필 곡선 계산 SSOT**: 미리보기, 문서 path 출력, editable path 변환에 흩어진 0.2 smoothing을 `splineControlPoint`로 통합했다. 같은 정점에서 같은 제어점을 사용한다. 기존 파일 형식·좌표 규칙을 유지하고 미리보기의 삼각함수 왕복만 벡터 계산으로 바꿨다. 미세한 부동소수점 문자열 차이는 가능하지만 저장/출력 공식은 그대로다. 기존 공개 export는 유지했다.
2. **키보드 입력 경계**: 세 곳의 텍스트 입력 판별을 `editor/keyboard.ts`로 모았다. Canvas와 toolbar가 Hook 모듈을 통해 순수 판별 함수를 가져오지 않게 했다. 기존 Hook export 경로도 호환 유지했다. 기존 일부 경로가 놓치던 빈 contenteditable 및 plaintext-only도 실제 편집 중에는 canvas 단축키를 막는다.
3. **파일 가져오기 책임**: 페이지에서 decoding·선택·문서 삽입·pending/error 관리를 `useArtworkImport`로 이동했다. SVG 크기 선검사는 파일 메뉴와 이미지 picker/drop 모두 `importSvgFile`을 사용한다. parser, 오류 문구, 이미지 배치, SVG의 Layers/이미지의 Properties 진입을 보존했다.
4. **인접한 비동기 수정**: 동시 가져오기의 진행 표시를 boolean 대신 미완료 개수에서 계산해 첫 완료가 다른 읽기의 표시를 끄지 않게 했다. 새 문서로 바꾼 뒤 이전 읽기가 실패해도 새 문서에 그 오류를 표시하지 않는다. 기존 성공 결과의 문서 ID 가드와 같은 정책이다. 가져오기를 취소하는 API나 큐·전역 store는 만들지 않았다.
