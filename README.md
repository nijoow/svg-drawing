# SVG Drawing

브라우저에서 SVG 도형과 자유 곡선을 그리고 편집할 수 있는 토이 프로젝트입니다.

[데모 보기](https://nijoow-drawing.vercel.app)

## 주요 기능

- 드래그로 사각형, 삼각형, 타원 그리기
- 정점을 찍어 열린 경로 및 닫힌 다각형 그리기
- 자유 드로잉을 부드러운 Bézier 경로로 변환
- 도형 이동, 크기 조절, 회전
- 채우기, 선 색상, 선 굵기, 투명도 변경
- ‘점 편집’에서 꼭짓점과 곡선 제어점을 드래그해 편집
- ‘점 추가’를 누르고 선 위를 클릭하거나 탭해 꼭짓점 추가
- 도형 삭제 및 레이어 순서 변경
- 같은 브라우저에서 마지막으로 편집을 마친 그림 자동 복원

## 단축키

| 키                   | 기능                  |
| -------------------- | --------------------- |
| `Ctrl/⌘ + Z`         | 실행 취소             |
| `Ctrl/⌘ + Shift + Z` | 다시 실행             |
| `V`                  | 도형 선택             |
| `A`                  | 정점 편집             |
| `N`                  | 자유 드로잉           |
| `P`                  | 정점 기반 경로 그리기 |
| `Enter`              | 열린 경로 완성        |
| `Escape`             | 경로 그리기 취소      |

## 구현 방식

- 정점 배열을 공통 도형 데이터로 사용해 SVG path로 렌더링합니다.
- 회전 전 좌표계에서 크기를 조절한 뒤 회전 좌표로 변환해 왜곡을 줄였습니다.
- 인접 입력 좌표로 곡선 제어점을 계산해 자유 드로잉을 보정합니다.
- 선택한 도형 ID를 기준으로 상태를 갱신해 다른 도형과 상태를 분리했습니다.

## 기술 스택

- Next.js 16, React 19, TypeScript 6
- Jotai, Tailwind CSS 4, Color

## 실행

Node.js 24 LTS 및 Yarn 4를 사용합니다.

```sh
corepack enable
yarn install --immutable
yarn dev
```
