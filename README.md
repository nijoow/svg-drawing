# SVG Drawing

브라우저에서 SVG 도형을 그리고 편집할 수 있는 인터랙션 토이 프로젝트입니다.

## Demo

https://nijoow-drawing.vercel.app

## 주요 인터랙션

- 드래그로 사각형, 삼각형, 타원 그리기
- 정점을 찍어 열린 path 또는 닫힌 polygon 그리기
- 펜 입력을 부드러운 Bézier path로 변환해 자유롭게 그리기
- 선택한 도형 이동, 크기 조절, 회전
- fill, stroke, 선 굵기, 투명도 변경
- 정점 위치와 기존 곡선 정점의 제어점 편집
- 도형 삭제 및 레이어 순서 변경
- 키보드 단축키
  - `V`: 도형 선택
  - `A`: 정점 편집
  - `N`: 자유 드로잉
  - `P`: 정점 기반 path 그리기
  - `Enter`: 열린 path 완성
  - `Escape`: 정점 그리기 취소

## 구현하면서 해결한 문제

### 도형 데이터를 정점 배열 중심으로 통일

사각형, 삼각형, 타원과 직접 그린 도형을 정점 기반 데이터로 관리하고 SVG path로 렌더링해 선택과 변형 로직을 함께 사용할 수 있도록 구성했습니다.

### 회전된 도형의 크기 조절

포인터 좌표를 도형의 회전 전 좌표계로 변환한 뒤 정점과 곡선 제어점의 위치를 새 크기에 맞게 remap하고, 다시 회전 좌표로 변환해 반영했습니다.

### 자유 드로잉 경로 보정

입력된 인접 좌표를 바탕으로 제어점을 계산하고 cubic Bézier command를 생성해 마우스 이동 경로를 부드러운 SVG path로 표현했습니다.

### 선택된 도형만 안전하게 갱신

선택된 drawing id를 기준으로 상태를 갱신해 여러 도형이 있을 때 이동·크기 조절·회전이 다른 도형에 영향을 주지 않도록 분리했습니다.
