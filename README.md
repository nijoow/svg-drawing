# SVG Drawing

브라우저에서 SVG 도형을 그리고 편집하며, 작업을 저장하고 SVG로 내보낼 수 있는 편집기입니다.

## Demo

https://nijoow-drawing.vercel.app

## 주요 기능

기존의 회색 플로팅 도구 막대와 흰 캔버스를 유지합니다. 오른쪽 **Layers / Properties / Artboards** 버튼으로 필요한 패널만 열고 닫을 수 있습니다.

- **작업 화면**: 줌·팬, 포인터 기준 확대, 화면 맞춤, 그리드, 객체 가장자리·중심 스냅과 안내선
- **선택·배치**: 드래그 영역 선택, Shift 추가 선택, 중첩 그룹, 복사·붙여넣기·복제, 정렬·간격 분배
- **레이어**: 이름, 표시·숨김, 잠금, 순서 변경, 그룹별 접기
- **벡터**: 사각형·타원·삼각형, 드래그 핸들을 지원하는 Bézier 펜, 자유 드로잉, 합치기·빼기·교집합·겹침 제외
- **경로 편집**: 곡선을 보존하는 분할, 점 삭제, 부드러운 점·모서리점, 직선화, 경로 열기·닫기, 자유 드로잉 단순화
- **스타일**: 채우기·테두리·투명도, 선형·방사형 그라디언트, 클리핑 마스크, 혼합 모드
- **텍스트**: 한글·여러 줄, 글꼴·크기·굵기·기울임·정렬·행간·자간
- **이미지**: PNG/JPEG/WebP 가져오기와 드롭, 원본을 보존하는 자르기, 밝기·대비·채도·색상·흑백·흐림 조정
- **아트보드**: 프리셋 및 선택 영역으로 생성, 크기·위치·이름, 객체 연결과 영역별 출력
- **문서**: 실행 취소·다시 실행, 자동 저장·복원, 편집 가능한 JSON 저장·열기, SVG 가져오기·출력, PNG 및 React SVG 출력

## 사용 흐름

왼쪽 도구에서 도형을 고르고 캔버스에 드래그합니다. **Pen**은 클릭으로 직선을, 클릭한 채 드래그하여 곡선을 만듭니다. `Enter`로 열린 경로를 완성하거나 시작점을 클릭해 닫습니다. **Edit points**에서는 점을 선택한 뒤 하단의 경로 편집 도구를 사용합니다.

여러 객체를 선택하면 하단 **Arrange**에서 그룹·정렬·간격을 조절하고, 그 위의 **Unite / Subtract / Intersect / Exclude**로 경로를 합성할 수 있습니다. 빼기는 가장 아래에 있는 선택 도형에서 위쪽 도형을 뺍니다. 클리핑은 맨 위의 선택 벡터 도형을 마스크로 사용하며 **Release mask**로 해제합니다.

**Text**로 캔버스를 클릭한 다음 **Properties**에서 내용을 입력합니다. 이미지는 왼쪽 이미지 버튼이나 캔버스 드롭으로 추가합니다. 원본 이미지 데이터는 유지되며 자르기·색 보정은 저장 후에도 다시 수정할 수 있습니다.

## 단축키

| 키                                                  | 동작                                      |
| --------------------------------------------------- | ----------------------------------------- |
| `V` / `A`                                           | 선택 / 점 편집                            |
| `P` / `N` / `T`                                     | 펜 / 자유 드로잉 / 텍스트                 |
| `H` / `Space`를 누른 채 드래그 / 마우스 가운데 버튼 | 화면 이동                                 |
| 휠 / `Ctrl` 또는 `⌘` + 휠                           | 화면 이동 / 포인터 기준 줌                |
| `+` / `-` / `Ctrl` 또는 `⌘` + `0`                   | 확대 / 축소 / 선택 또는 그림 맞춤         |
| `Shift` 클릭 / 영역 드래그                          | 선택 추가·해제 / 영역 선택                |
| `Alt` 클릭 / 변형 중 `Alt`                          | 그룹 안의 개별 객체 선택 / 스냅 해제      |
| 변형 중 `Shift`                                     | 이동 축·비율·45도 회전 제한               |
| 방향키 / `Shift` + 방향키                           | 1 / 10 문서 단위 이동                     |
| `Ctrl` 또는 `⌘` + `A`, `C`, `X`, `V`, `D`           | 전체 선택, 복사, 잘라내기, 붙여넣기, 복제 |
| `Ctrl` 또는 `⌘` + `G` / `Shift` + `G`               | 그룹 / 그룹 해제                          |
| `Delete` 또는 `Backspace`                           | 선택 삭제; 점 편집에서는 선택한 점 삭제   |
| `Enter` / `Escape`                                  | 펜 경로 완성 / 진행 중 조작 취소          |
| `Ctrl` 또는 `⌘` + `Z` / `Shift` + `Z` 또는 `Y`      | 실행 취소 / 다시 실행                     |
| `Ctrl` 또는 `⌘` + `S`                               | 프로젝트 파일 저장                        |

입력창과 한글 조합 중에는 편집 단축키가 텍스트 입력을 가로채지 않습니다. 복사·붙여넣기는 현재 편집기 내부 클립보드를 사용합니다.

## 문서와 출력

- **File → Save project / Open project**: `.svg-drawing.json`에 정점, 레이어, 그룹, 아트보드, 이미지 원본, 텍스트와 효과를 보존합니다.
- **Import SVG**: 기본 벡터 도형·경로, 변환·그룹, 단순 그라디언트를 편집 가능한 객체로 가져옵니다. 지원하지 않는 요소나 외부 참조는 오류로 안내하고 기존 문서를 유지합니다.
- **Export SVG / Export React**: 전체 그림 또는 선택한 아트보드 영역을 출력합니다. 경로 좌표 정밀도를 조절할 수 있으며 React 출력은 재사용 가능한 TSX 컴포넌트입니다.
- **Export PNG**: 1×·2×·3× 해상도와 투명·흰 배경을 선택합니다. 한 변 16,384px, 전체 64MP 이내에서 출력합니다.
- **자동 저장**: 완료한 편집을 현재 브라우저에 저장합니다. 다른 기기·브라우저로 옮길 때는 프로젝트 파일을 사용합니다.
- **복구·여러 탭**: 손상된 저장본이나 다른 탭의 변경은 자동으로 덮어쓰지 않습니다. 원본 복구 파일을 저장하거나 현재 문서를 사용할지 선택할 수 있습니다. 저장 공간 부족은 상태 표시로 안내합니다.
- **실행 취소**: 최근 50개 편집을 되돌립니다. 드래그·색상·이미지 슬라이더 조작은 한 단계로 기록합니다. 새 문서 열기와 새로고침은 기록을 초기화합니다.

프로젝트 형식은 **버전 2**이며 버전 1 파일은 열 때 변환됩니다. 파일 10MiB, 객체 1,000개, 마스크·복합 경로를 포함한 정점 100,000개, 그룹 1,000개, 아트보드 100개를 검증 한도로 사용합니다. 이미지 가져오기는 파일 6MiB, 한 변 8,192px 및 전체 32MP까지 지원하며, 임베딩 후 전체 문서 한도도 적용됩니다. 이 수치는 실시간 성능 벤치마크가 아닙니다.

## 지원 범위

벡터 제작과 기본 이미지 편집을 함께 수행하는 브라우저 편집기입니다. Photoshop의 픽셀 브러시·복원·RAW 현상이나 Illustrator의 인쇄용 CMYK·ICC·PDF/AI/PSD 호환까지 제공하지는 않습니다. 텍스트는 편집 가능한 SVG 텍스트로 유지되며 폰트 임베딩·윤곽선 변환은 지원하지 않아 다른 기기에서 글꼴이 달라질 수 있습니다. SVG 가져오기는 전체 SVG 표준을 지원하지 않으며 이미지·텍스트·필터·마스크가 포함된 SVG의 재편집에는 프로젝트 JSON을 사용합니다. 회전된 텍스트·이미지를 포함한 다중 선택 크기 조절은 직사각형 형태를 유지하도록 비율을 제한합니다.

## 구현하면서 해결한 문제

### 도형 데이터를 정점 배열 중심으로 통일

사각형, 삼각형, 타원과 직접 그린 도형을 정점 기반 데이터로 관리하고 SVG path로 렌더링해 선택과 변형 로직을 함께 사용할 수 있도록 구성했습니다.

### 회전된 도형의 크기 조절

포인터 좌표를 도형의 회전 전 좌표계로 변환한 뒤 정점과 곡선 제어점의 위치를 새 크기에 맞게 remap하고, 다시 회전 좌표로 변환해 반영했습니다.

### 자유 드로잉 경로 보정

입력된 인접 좌표를 바탕으로 제어점을 계산하고 cubic Bézier command를 생성해 마우스 이동 경로를 부드러운 SVG path로 표현했습니다.

### 선택된 도형만 안전하게 갱신

선택된 drawing id를 기준으로 상태를 갱신해 여러 도형이 있을 때 이동·크기 조절·회전이 다른 도형에 영향을 주지 않도록 분리했습니다.

## 검증

```bash
yarn typecheck
yarn lint
yarn test
yarn build
```

회귀 테스트는 v1→v2 변환과 파일 검증, 저장·복원, 실행 취소, 그룹·클립보드·정렬, 줌 좌표, Bézier 분할·경로 편집·스냅, 마스크·그라디언트·이미지·한글 텍스트, 도형 합성 면적과 React 출력 구문을 검증합니다. Node 테스트 러너와 프로젝트의 TypeScript 컴파일러를 사용합니다.

Chromium에서도 생성→선택·변형→실행 취소→저장·복원→SVG/PNG/React 출력 흐름과 좁은 화면 배치를 확인했습니다. 공유 렌더러는 화면과 SVG 출력의 그라디언트·혼합·마스크·이미지·텍스트·효과 픽셀 일치 검사로 검증했습니다.

현재 검증 환경은 Node 18.20.8과 Yarn 3.6.0입니다. 기존 Next 13 / Yarn PnP 조합은 Node 24에서 로더 오류가 재현되므로 런타임·프레임워크 업그레이드는 별도 호환성 검증이 필요합니다.
